En tant que TRPPU

Je veux que les informations de trafic d'un scénario modifé puissent être mises à jour en base 

Afin de disposer des trafics "recalculés" par produit pour le scénarios modifié.

Pour cela, créer un service dans yb04 qui mettra à jour la table trppu_tmh avec les informations de trafics du tableau TMH de l'IHM listées ci-dessous.

le service doit recevoir en paramètre les informations suivantes :

id_scenario > id du scénario en cours
co_produit > code du produit 
volume_realise > trafic réalisé (=constaté) pour le produit concerné
volume_previsionnel > trafic prévisionnel pour le produit concerné
moyenne_journalière > la moyenne du trafic sur une journée
moyenne_hebdo > la moyenne du trafic sur une semaine
exclusion > flag indiquant si le produit est exclu du calcul des trafics au pdi ou pas
manuel > flag indiquant si la ligne a été ajouté manuellement ou pas, 1 si manuel 0 si auto
id_rh > l'id rh crypté de l'utilisateur qui a mise à jour les informations crypté

dans la table trppu_tmh : les trafics de chaque produit pour le scénario présent dans le tableau TMH de l'IHM sont à mettre à jour (update) avec les informations suivantes :

volume_realise > trafic réalisé (=constaté) pour le produit concerné
volume_previsionnel > trafic prévisionnel pour le produit concerné
moyenne_journalière > la moyenne du trafic sur une journée
moyenne_hebdo > la moyenne du trafic sur une semaine
dt_calcul > date du calcul (= mise à jour) des trafics pour le produit
bl_exclu  > flag indiquant si le produit est exclu du calcul des trafics au pdi ou pas
bl_manuel > flag indiquant si la ligne a été ajouté manuellement ou pas, 1 si manuel 0 si auto
id_rh > l'id rh crypté de l'utilisateur qui a mise à jour les informations crypté




Critère d'acceptance 

Après la mise à jour du scénario et l'actualisation des trafics sur l'IHM :

Vérifier que les informations de trafic sauvegardées dans la table trppu_tmh sont correctes et en phase avec les trafics de l'IHM

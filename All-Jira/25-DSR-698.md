TRPPU

Je souhaite

créer une nouvelle version de clés associée à un référentiel donné pour les sites

Afin de

préparer le calcul d'un nouvel ensemble de clés de répartition.

Description

Lorsqu'un nouveau référentiel pour un site est disponible :

arrivée de nouveaux PDI ;
changement de rattachement ;
évolution de trafic ;

une nouvelle version de clés du site doit être créée.

Cette version constitue le conteneur des clés calculées.

RG

Toute modification du périmètre PDI ou des trafics d'un site entraîne la création d'un nouveau référentiel et d'une nouvelle version de clés exclusivement pour le site concerné.

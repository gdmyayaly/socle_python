En tant que TRPPU

Je veux pouvoir récupérer les informations du paramétrage prévisionnel d'un scénario

Afin de les charger dans l'IHM lors de l'édition d'un scénario.

Pour cela, créer un service dans yb04 qui recevra en paramètre l'ID du scénario à partir duquel le service récupérera le paramétrage prévisionnel du scénario dans la table "trppu_scenario_variations_prev".

Toutes les lignes de la table "trppu_scenario_variations_prev" dont l'id de scénario correspond à celui reçu en paramètre par le service yb04 sont à récupérer.

Il y a une ligne par objet/produit avec les informations suivantes : 

co_produit > code du produit 
variation_pct > le % de variation pour le produit

Ces informations seront utilisées par l'IHM pour renseigner le tableau du paramétrage prévisionnel du scénario

Critère d'acceptance 

Lors de l'édition d'un scénario dans l'IHM :

le service est appelé pour le scénario édité
les paramétrages prévisionnels sont récupérés pour tous les produits du scénario présent dans la table en base, ceux dont le paramétrage était celui par défaut ne sont pas en base, par défaut leur paramètrage est à 0%
Vérifier dans les logs kibana que l'appel a bien été tracé et indique l'id du scénario pour le quel les paramètres sont récupérés.
Vérifier avec la base de données que les informations récupérées correspondent bien à celles du scénario édité.

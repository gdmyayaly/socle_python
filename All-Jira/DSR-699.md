


En tant que

TRPPU

Je souhaite

calculer les clés de répartition des PDI à partir du référentiel source et des agrégats site

Afin de

alimenter la table des clés calculées.

Description

Chaque clé est calculée à partir :

TRPPU_CLES_REPARTITION

et :

TRPPU_SITE_TRAFIC

pour une version donnée.

Table concernée

TRPPU_CLES_REPARTITION_CALCULE




    id_cle_repartition
    id_version_cle
    id_referentiel
    id_pdi
    co_regate_site
    cle_colis 
    cle_oo
    cle_3s 
    cle_potentielip 
    date_creation 




Formules
Clé colis

 
trafic_colis_pdi
/
somme_trafic_colis_site
 

Clé OO

 
trafic_oo_pdi
/
somme_trafic_oo_site
 

Clé 3S

 
trafic_3s_pdi
/
somme_trafic_3s_site
 

Clé potentiel IP

 
potentielip_pdi
/
somme_potentielip_site




Contrôle

 
Après chaque calcul de clés d'un site, exécuter un contrôle :
 
Pour chaque site :
    somme(clé_colis)
    somme(clé_oo)
    somme(clé_3s)
    somme(clé_potentielip)
 
Résultat attendu :
≈ 1 :

0,9999 ≤ somme ≤ 1,0001

 
Si ce n'est pas le cas :
 
alerte dans les logs indiquant le site et la clé et la somme obtenue en dehors de la plage
 
car cela signifie généralement :

un PDI oublié ;
un doublon ;
une erreur de périmètre ;
un problème d'arrondi ou de calcul.
Critères d'acceptation
CA1

Une ligne de clés est créée pour chaque PDI actif du référentiel.

CA2

Toutes les clés sont rattachées à une version.

CA3

La somme des clés d'un site vaut 1.

CA4

Aucune clé d'une version existante n'est modifiée.

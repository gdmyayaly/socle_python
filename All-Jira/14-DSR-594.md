En tant que TRPPU,

Je veux pouvoir récupérer les données de trafics 

Afin de les envoyer à l'IHM TRPPU

Pour cela une API "Databricks" (composant "compute"  ou sqlWarehouse ou autre) doit être créé.

Cette API doit recevoir en paramètre au minimum le code regate du site et la période sur laquelle les données doivent être récupérées.

La période doit contenir la date de début et la date de fin au format AAAAMMJJ.

La période pour laquelle les données sont à récupérer ne doit pas dépasser 2 ans, les dates reçues en paramètres ne doivent donc pas dépasser cette durée.

Le résultat qui doit être renvoyé au service appelant est la somme des trafics des objets ci-dessous sur la période et le site reçu en paramètres.




Les trafics à renvoyer sont ceux des objets suivant : 

OO
OS
PRESSE
PPI
COLIS
IP




Les tables à partir desquelles les informations sont récupérées sont : 

g_mdp_trafics_jour_actualise
g_mdp_trafics_mois_actualise
g_mdp_trafics_semaine_actualise




Dans ces tables les informations de trafics à récupérer sont : 

le trafic retenu correspondant à l'information "nb_objet_retenu" (trafic brut)
le trafic prévisionnel correspondant à l'information "nb_objet_prevu_recadre_bu"  




Filtrage des données dans la requête sql :

Les dates de la période sont à rechercher sur le champ :
"da_comptage" pour la table agrégée à la journée.
"co_semaine_comptage" pour la table agrégée à la semaine.  format : "AAAA-NS"  (NS= n° de la semaine, exemple : 2026-12 pour la 12ème semaine de l'année)
"co_mois_comptage" pour la table agrégée aux mois. format "AAAA-MOIS" (exemple : 2026-03 pour mars 2026)

               => Selon la table interrogée, le format des dates de la période sont à adapter par rapport au format utilisé dans la table requêtée.

Le code regate du site correspond au champ "co_regate" dans les tables.

Critères d'acceptance :

appeler l'API "Databricks" avec différent paramètres et vérifier son comportement et les informations retournées :

avec juste un code regate  => doit retourner le fait qu'il manque les paramètres de la période et rappeler les paramètres
avec juste une période => doit retourner le fait qu'il manque le paramètre régate et rappeler les paramètres
avec juste une date de début => doit retourner le fait qu'il manque des paramètres et rappeler les paramètres
avec juste une date de fin => doit retourner le fait qu'il manque des paramètres et rappeler les paramètres
avec code regate, date de début et date de fin pour une période de plus de 2 ans => doit retourner le fait que la période dépasse les 2 ans d'interrogation permis et rappeler les paramètres
avec code regate, date de début et date de fin pour une période de 2 ans  => doit retourner le trafics pour le site sur la période demandée
avec code regate, date de début et date de fin pour une période de moins de 2 ans  => doit retourner le trafics pour le site sur la période demandée
vérifier que le retour obtenu correspond bien à une "ligne par objet et un nombre correspondant à la somme des trafics pour l'objet concerné"
faire une requête en base pour vérifier que le résultat est correcte aussi bien en trafics qu'en objets renvoyés.

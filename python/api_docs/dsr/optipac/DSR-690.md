Contexte

OPTIPACC doit pouvoir connaître les scénarios TRPPU disponibles pour un site donné afin de permettre à l'utilisateur de sélectionner un scénario exploitable.

Seuls les scénarios :

au statut Validé ;
dont les trafics Agrébal ont déjà été calculés ;

doivent être proposés à OPTIPACC.

User Story

En tant que application OPTIPACC

Je souhaite récupérer la liste des scénarios exploitables d'un site

Afin de permettre à l'utilisateur de sélectionner un scénario dont les trafics sont prêts à être utilisés dans OPTIPACC. 

Règles de gestion
RG1

Le service reçoit en entrée un code Regate. 

RG2

Le service retourne uniquement les scénarios du site demandé.

RG3

Seuls les scénarios au statut :

Validé

sont retournés.

RG4

Un scénario n'est retourné que si les calculs des trafics Agrébal ont été exécutés avec succès (le champ "trafic_agrebal_calcule" de la table trppu_scenario vaut 1).

RG5

Les scénarios « En cours », « Simulation» ou tout autre statut ou dont les calculs Agrébal ne sont pas terminés ne doivent pas être retournés.

Contrat de service
Nom du service

S_SiteListeScenarios

Entrée




{   "codeRegate": "123456" }




Sortie

 
{
  "codeRegate": "123456",
  "scenarios": [
   

{       "id_scenario": 125,       "lb_scenario": "Scénario Septembre 2026",     }

,
   

{       "id_scenario": 128,       "lb_scenario": "Scénario Vieillissement",     }

  ]
}
 

Gestion des erreurs
Cas 1 – Aucun Scénario 
Message

Aucun scénario trouvé pour le site <code regate>.




Cas 4 – Erreur technique
Message

Une erreur est survenue lors de la récupération des scénarios.

Critères d'acceptation
CA1

Étant donné un site possédant plusieurs scénarios,

Lorsque OPTIPACC appelle le service,

Alors seuls les scénarios au statut Validé sont retournés.

CA2

Les scénarios dont les trafics Agrébal ne sont pas calculés ne sont pas retournés.

CA3

La réponse contient au minimum :

l'identifiant du scénario ;
son libellé ;
CA4

Si aucun scénario éligible n'existe pour le site, le service retourne le message 'aucun scenario pour le site "<code regate>". 

Notes techniques

Ce service sera utilisé par OPTIPACC pour alimenter la liste des scénarios sélectionnables avant récupération des trafics site et des trafics Agrébal associés.

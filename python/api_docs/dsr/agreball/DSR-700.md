En tant que
TRPPU

Je souhaite
associer une version de clés à un scénario

Afin de
garantir la reproductibilité des calculs réalisés.

Description
Lors du calcul des trafics pdi et agrébal d'un scénario :

un référentiel du site du scénario est sélectionné ;
une version de clés du site du scénario est sélectionnée.
Le scénario conserve cette référence même si de nouvelles versions sont créées ultérieurement.

Table concernée
TRPPU_SCENARIO

Données enregistrées
id_referentiel
id_version_cle

Pour l'id_scenario pour lequel les trafics pdi et agrébal sont calculés 

Exemple
 
SCENARIO_A → Réf 1 → Version 1
SCENARIO_B → Réf 1 → Version 1
SCENARIO_C → Réf 2 → Version 2
 

Critères d'acceptation
CA1
Chaque scénario possède une version de clés.

CA2
Un scénario existant conserve la version utilisée lors de son calcul.

CA3
Il est possible de retrouver les clés utilisées par un scénario.

CA4
Il est possible de retrouver les données source ayant servi à calculer ces clés.

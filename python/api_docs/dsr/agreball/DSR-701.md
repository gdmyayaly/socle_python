Objectif
Contrôler l'éligibilité d'un scénario avant lancement des calculs de trafic PDI et Agrébal

User Story
En tant que  TRPPU,

Je souhaite pouvoir lancer le batch YB05 en mode contrôle d'éligibilité pour un scénario donné,

Afin de vérifier qu'il remplit toutes les conditions nécessaires avant d'autoriser le calcul de ses trafics PDI et Agrébal.

Commande d'exécution
Le batch doit proposer un mode de contrôle dédié :

YB05 ELIGIBILITE <id_scenario>

Exemple :

YB05 ELIGIBILITE 12345

ou

YB05 --traitement=ELIGIBILITE --scenario=12345

Description fonctionnelle
Le traitement ne réalise aucun calcul de trafic.

Il contrôle uniquement qu'un scénario est éligible au calcul.

Le résultat doit être affiché dans les logs et retourné sous forme d'un état :

ELIGIBLE AU CALCUL COMPLET DES TRAFICS (PDI + Agrébals)

ou

NON ELIGIBLE

accompagné de la liste des motifs bloquants.

Règles d'éligibilité
Règle 1 : Le scénario doit exister
Contrôle :

 
SELECT *
FROM trppu_scenario
WHERE id_scenario = :id_scenario
 

Résultat attendu :

1 scénario trouvé

Erreur :

Scénario inexistant

Règle 2 : Le scénario doit être au statut VALIDE
Condition :

STATUT = VALIDE

Erreur :

Le scénario n'est pas validé

Règle 3 : Le scénario doit être figé
Condition :

EST_FIGE = 1

Erreur :

Le scénario n'est pas figé

Règle 4 : Aucun calcul ne doit être déjà en cours
Condition :

CALCUL_TRAFIC_EN_COURS = 0

Erreur :

Un calcul de trafic est déjà en cours

Règle 5 : Les trafics PDI ne doivent pas déjà être calculés
Condition :

TRAFIC_PDI_CALCULE = 0

Erreur :

 
Les trafics PDI sont déjà calculés
 

Règle 6 : Les trafics Agrébal ne doivent pas déjà être calculés
Condition :

TRAFIC_AGREBAL_CALCULE = 0

Erreur :

Les trafics Agrébal sont déjà calculés

Règle 7 : Une version PIC doit être associée au scénario
Condition :

ID_PIC_VERSION > 0

Erreur :

Aucune version PIC associée au scénario

Règle 8 : Les coefficients de rétention doivent exister
Contrôle :

présence des coefficients  dans :
 
TRPPU_PIC_COEFFICIENTS

pour :
 
ID_PIC_VERSION du scénario

Erreur :
 
Aucun coefficient de rétention trouvé
pour la version PIC du scénario 

Règle 9 : Une version de clés de répartition active doit être disponible
Le batch doit vérifier qu'une version de clés active existe pour le site du scénario dans la table trppu_version_cle au moment du contrôle.

Contrôle :

SELECT id_version_cle
FROM trppu_version_cle
WHERE co_regate = :coRegate
AND actif = 'O'

Erreur :

Aucune version de clés active disponible

Règle 10 : Un référentiel actif doit exister
Le batch doit vérifier qu'un référentiel actif est disponible pour le site du scénario dans la table trppu_referentiel.

Contrôle :

SELECT id_referentiel
FROM trppu_referentiel
WHERE co_regate = :coRegate
ORDER BY id_referentiel DESC
LIMIT 1

Ou :

SELECT id_referentiel
FROM trppu_version_cle
WHERE co_regate = :coRegate
AND actif = 'O'

qui doit renvoyer le même id_referentiel.

Erreur :

Aucun référentiel actif disponible

Règle 11 : Le site doit posséder des Agrébals
Contrôle :

présence d'au moins un Agrébal pour :

CO_REGATE du scénario

dans la table :

trppu_trafic_agrebal

Erreur :

Aucun Agrébal trouvé sur le site

Règle 12 : Les Agrébals doivent contenir des PDI
contôle au moins à faire pour un agrébal

Erreur :

Aucun PDI rattaché aux Agrébals du site

Résultat attendu
Cas nominal
 
--------------------------------------------------
Contrôle d'éligibilité YB05
Scénario : 12345
--------------------------------------------------
 
[OK] Scénario trouvé
[OK] Statut VALIDE
[OK] Scénario figé
[OK] Aucun calcul en cours
[OK] Trafic PDI non calculé
[OK] Trafic Agrébal non calculé
[OK] Version PIC trouvée
[OK] Coefficients de rétention disponibles
[OK] Référentiel actif disponible
[OK] Version de clés active disponible
[OK] Agrébals trouvés
[OK] PDI trouvés
 
RESULTAT : ELIGIBLE AU CALCUL COMPLET DES TRAFICS (PDI + Agrébals)
 

Cas bloquant
 
--------------------------------------------------
Contrôle d'éligibilité YB05
Scénario : 12345
--------------------------------------------------
 
[OK] Scénario trouvé
[KO] Le scénario n'est pas figé
[KO] Aucun coefficient de rétention trouvé
[OK] Agrébals trouvés
 
RESULTAT : NON ELIGIBLE
 
Motifs :

scénario non figé
coefficients de rétention absents
 
Critères d'acceptation
CA-01
Étant donné un identifiant de scénario inexistant,

Quand je lance :

YB05 ELIGIBILITE 999999

Alors le batch retourne :

NON ELIGIBLE

avec le motif :

Scénario inexistant

CA-02
Étant donné un scénario au statut VALIDE et figé,

Quand toutes les données nécessaires sont présentes,

Alors le batch retourne :

ELIGIBLE AU CALCUL COMPLET DES TRAFICS (PDI + Agrébals)

CA-03
Étant donné un scénario dont le calcul est déjà en cours,

Quand le contrôle est lancé,

Alors le batch retourne :

NON ELIGIBLE

avec le motif :

Un calcul de trafic est déjà en cours

CA-04
Étant donné un scénario dont les trafics ont déjà été calculés,

Quand le contrôle est lancé,

Alors le batch retourne :

NON ELIGIBLE

avec le motif correspondant.

CA-05
Le traitement ELIGIBILITE ne doit :

insérer aucune donnée ;
modifier aucune donnée ;
mettre à jour aucun statut ;
Il s'agit exclusivement d'un traitement de contrôle préalable

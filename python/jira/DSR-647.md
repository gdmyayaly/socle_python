En tant que TRPPU

Je veux que les informations d'un site qui n'existerait pas en base TRPPU soit enregistrer en base 

Afin de disposer de la liste des sites pour lesquelles des scénarios TRPPU ont été créé.

Pour cela, créer un service dans yb04 qui mettra à jour la table trppu_site avec les informations du site lors de la création d'un scénario.

le service de création d'un site doit recevoir en paramètres : 

co_regate > code regate du site
lb_type_entite_regate_court > libellé court du site
type_site > type de site 
co_roc > code roc du site
 

trppu_site : Si le site n'existe pas dans la table trppu_site, il est ajouté en renseignant les informations suivantes : 

co_regate > code regate du site
lb_type_entite_regate_court > libellé court du site
type_site > type de site 
co_roc > code roc du site
dt_maj > date de création du site sur la BD trppu
 

Critère d'acceptance 

Après la création d'un scénario :

Vérifier dans la table trppu_site que le site pour lequel le scéanrio a été créé existe et que toutes les informations ci-dessus sont renseignées.

En tant que TRPPU

Je veux que les informations précisant si un trafic doit être exclu du scénario ou les informations de trafic ajoutée manuellement soient enregistrer en base 

Afin de disposer de toutes les informations de trafics par produit pour le scénarios nécessaire pour calculer ensuite le trafic au PDI via yb05.

Pour cela, modifier le service utilisé dans yb04 qui met à jour la table trppu_tmh pour que les paramètres qu'il reçoit inclus les informations suivantes :

Paramètres supplémentaire à prendre en compte par le service :

lb_manuel > la ligne de trafic a été ajouté manuellement
 

Pour rappel les autres paramètres déjà utilisés par le service sont : 

id_scenario > id du scénario en cours
co_produit > code du produit 
volume_realise > trafic réalisé (=constaté) pour le produit concerné
volume_previsionnel > trafic prévisionnel pour le produit concerné
moyenne_journalière > la moyenne du trafic sur une journée
moyenne_hebdo > la moyenne du trafic sur une semaine
exclusion > flag indiquant si le produit est exclu du calcul des trafics au pdi ou pas
trppu_tmh : une ligne est insérée pour chaque produit présent dans le tableau TMH de l'IHM avec les informations suivantes : 

id_tmh > créé automatiquement par le système mysql
id_scenario > id du scénario en cours
co_produit > code du produit 
volume_realise > trafic réalisé (=constaté) pour le produit concerné
volume_previsionnel > trafic prévisionnel pour le produit concerné
moyenne_journalière > la moyenne du trafic sur une journée
moyenne_hebdo > la moyenne du trafic sur une semaine
dt_calcul > date du calcul (= mise à jour) des trafics pour le produit
bl_exclu  > flag indiquant si le produit est exclu du calcul des trafics au pdi ou pas
NB :  lors de la création ou lors de l'édition d'un scénario, si la ligne du produit n'existait pas pour le scénario, elle est insérée dans la table trppu_tmh

si la ligne pour le produit existait déjà en base, elle est mise à jour pour les informations qui ont changés. 

Critère d'acceptance 

Après la création du scénario et la mise à jour du tableau des trafics sur l'IHM:

Vérifier que les informations de trafic sauvegardées dans la table trppu_tmh sont correctes et en phase avec les trafics de l'IHM

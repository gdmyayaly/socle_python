En tant que TRPPU

Je veux que les informations de trafic d'un scénario soient mise à jour en base en cas de modification des trafics initiaux

Afin d'actualiser les trafics moyen hebdo des produits modifiés pour le scénario.

Pour cela, créer un service dans yb04 qui mettra à jour la table trppu_tmh avec les informations de trafics moyen hebdo qui ont été modifiés dans le tableau tmh et qui sont celles ci-dessous.

le service doit recevoir en paramètre :

l'id du scénario
le code produit dont le trafic a changé
le nouveau volume de trafic pour le produit
la moyenne du trafic sur une journée pour le produit
la moyenne du trafic sur une semaine pour le produit
 

trppu_tmh : la ligne du scénario pour le produit dont le trafic a changé est à mètre à jour en modifiant les infos : 

volume_realise > le nouveau volume de trafic pour le produit
moyenne_journalière > la moyenne du trafic sur une journée pour le produit
moyenne_hebdo > la moyenne du trafic sur une semaine pour le produit
dt_calcul > date du calcul (= mise à jour) des trafics pour le produit
 

Critère d'acceptance 

Après la mise à jour du tableau des trafics sur l'IHM :

Vérifier que les informations de trafic sauvegardées dans la table trppu_tmh sont correctes pour les produits du scénarios dont le trafic a changé depuis sa création et en phase avec les trafics affichés dans l'IHM.

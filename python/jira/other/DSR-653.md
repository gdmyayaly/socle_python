En tant que TRPPU

Je veux pouvoir récupérer les informations d'ajout des comptages d'objets d'un scénario

Afin de les charger lors de l'édition d'un scénario

Pour cela, créer un service dans yb04 qui recevra en paramètre l'ID du scénario pour lequel les comptages sont à récupérer de la table "trppu_scenario_comptages".

Toutes les lignes présentes dans la table pour l'id scénario sont à récupérer avec les informations suivantes : 

co_produit
dt_comptage  (date d'ajout/modification du comptage)
nb_produit  (trafic ajouté)
Les informations récupérées seront utilisées pour renseigner le tableau des "comptage manuels" à l'édition d'un scénario.

 

Critères d'acceptances : 

Lors de l'édition d'un scénario dans l'IHM :
le service est appelé pour le scénario édité
les comptages sont récupérés pour le scénario présent dans la table en base
les différents comptages sont bien renseignés dans le tableau correspondant sur l'IHM
Vérifier dans les logs kibana que l'appel a bien été tracé et indique l'id du scénario pour le quel les paramètres sont récupérés.
Vérifier avec la base de données que les informations récupérées correspondent bien à celles du scénario édité.

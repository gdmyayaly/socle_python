En tant que TRPPU

Je veux que les informations de trafic d'un scénario soient récupéré de la base 

Afin d'afficher les trafics par produit dans le tableau "TMH" de l'IHM pour le scénarios.

Pour cela, créer un service dans yb04 qui recevra en paramètre l'ID du scénario pour l'utiliser afin de récupérer les trafics du scénario à partir de la table trppu_tmh.

Les informations de trafics à récupérer sont les suivantes : 

co_produit > code du produit 
volume_realise > trafic réalisé (=constaté) pour le produit concerné
volume_previsionnel > trafic prévisionnel pour le produit concerné
moyenne_journalière > la moyenne du trafic sur une journée
moyenne_hebdo > la moyenne du trafic sur une semaine
bl_exclu  > flag indiquant si le produit est exclu du calcul des trafics au pdi ou pas
Toutes les lignes dont l'id de scénario dans la table trppu_tmh correspond sont à récupérer. Il y a une ligne par objet/produit

Ces informations seront utilisées par l'IHM pour renseigner le tableau TMH du scénario

 

Critère d'acceptance 

Lors de l'édition d'un scénario dans l'IHM :

le service est appelé pour le scénario édité
et les trafics sont récupérés et affichés dans le tableau TMH
Vérifier dans les logs kibana que l'appel a bien été tracé et indique l'id du scénario pour le quel les trafics sont récupérés.
Vérifier avec la base de données que les informations récupérées correspondent bien au scénario édité.
dans le cas d'un produit exclu du calcul des trafics au pdi, la ligne du produit est "grisée"

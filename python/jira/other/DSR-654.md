Afin de le consulter ou de le modifier

Pour cela lorsque un scénario présent dans la liste des scénarios du sites est sélectionné en édition les étapes ci-dessous doivent être réalisées pour afficher tous les éléments du scénario choisi.

Le slider s'active et toutes les informations qu'il affiche correspondent à celles du scénario sélectionné avec les dates sauvegardés en base : 
DSR-655 TRPPU : Récupérer les périodes d'un scénario - DSI BSCC-Jira-Gestion des évènements projets
Le nombre de jour de la semaine choisit pour le scénario est renseigné (5 si jours ouvrés, 6 si jours ouvrables) avec la valeur sauvegardé en base :
DSR-655 TRPPU : Récupérer les périodes d'un scénario - DSI BSCC-Jira-Gestion des évènements projets
Le tableau des trafics moyen hebdomadaire est renseigné avec les trafics du scénario qui sont sauvegardés en base pour le scénario :
DSR-650 TRPPU : Récupération des informations de trafic moyen hebdo d'un scénario - DSI BSCC-Jira-Gestion des évènements projets
Le tableau des comptages manuels est renseigné avec les comptages du scénario qui sont sauvegardés en base pour le scénario :
DSR-653 TRPPU : Récupération des comptage d'un scénario - DSI BSCC-Jira-Gestion des évènements projets
Le tableau des paramétrages de variation du trafic prévisionnel est renseigné avec les variations de trafics qui sont sauvegardés en base pour le scénario :
DSR-651 TRPPU : Récupération du paramétrage de prévision d'un scénario - DSI BSCC-Jira-Gestion des évènements projets
Le tableau des périodes neutralisées est renseigné avec les jours fériés sauvegardés en base pour le scénario :
DSR-652 TRPPU : Récupération des périodes neutralisées d'un scénario - DSI BSCC-Jira-Gestion des évènements projets
Le tableau des périodes saisonnières neutralisées est renseigné avec la période saisonnière sauvegardés en base pour le scénario : 
DSR-652 TRPPU : Récupération des périodes neutralisées d'un scénario - DSI BSCC-Jira-Gestion des évènements projets

DSR-652 TRPPU : Récupération des périodes neutralisées d'un scénario - DSI BSCC-Jira-Gestion des évènements projets

En tant que TRPPU

Je veux pouvoir récupérer les périodes qui ont été neutralisées pour un scénario

Afin de les charger dans l'IHM lors de l'édition d'un scénario.

Pour cela, créer un service dans yb04 qui recevra en paramètre l'ID du scénario à partir duquel les périodes neutralisées seront récupérées de la table "trppu_neutralisations".

Toutes les lignes de la table "trppu_neutralisations" dont l'id de scénario correspond à celui reçu en paramètre par le service yb04 sont à récupérer avec les informations suivantes  :

dt_debut
dt_fin
nb_jour
type
Dans l'IHM, les 3 "tableaux" des périodes neutralisées sont mis à jour en fonction du type de la période récupérée :

si le type est "FERIE":
La liste des jours exclus tableau des paramètres "période neutralisée" est renseigné avec les jours correspondant
Dans ce cas pour chaque jour "FERIE" la date de debut est égal à la date de fin 
le nombre de jour pour chaque "FERIE" vaut 1
Le nombre de jour "FERIE" afficher dans le paramétrage est la somme du nombre de jour "FERIE" trouvé
Si le type est "PEAK":
Cela veut dire qu'une peak période avait été définié/activé
le tableau de la peak période est celui à renseigner avec les date de début et de fin récupéré
le nombre de jour à afficher dans le tableau "période Neutralisation de la peak période" est celui récupéré
Il n'existe qu'1 seule ligne "PEAK" récupérée pour le scénario
le bouton d'activation de la peak période est "activé" et vert
Si le type est "SAISON":
Cela veut dire qu'une période saisonnière avait été définié/activé
le tableau de la période saisonnière est celui à renseigner avec les date de début et de fin récupéré
le nombre de jour à afficher dans le tableau "période saisonnière" est celui récupéré
Il n'existe qu'1 seule ligne "SAISON" récupérée pour le scénario
le bouton d'activation de la période saisonnière est "activé" et vert
Si un ou plusieurs types n'existent pas dans la table en base, cela veut dire que les périodes correspondantes n'ont pas été neutralisées et ce sont donc les valeur par défaut qui doivent être affichées dans l'IHM, à savoir : 
pour les jours fériés : aucun, la liste est vide
pour la peak période (PEAK) : le bouton est désactivé pour indiquer que la période n'est pas neutralisée
pour la période saisonnière (SAISON) : le bouton est désactivé pour indiquer que la période n'est pas neutralisée
 

Critère d'acceptance 

Lors de l'édition d'un scénario dans l'IHM :

le service est appelé pour le scénario édité
les périodes neutralisées sont récupérés pour le scénario présent dans la table en base
les paramètres des périodes neutralisées sont bien renseignés en fonction des types de périodes récupérées
si un type de période n'est pas récupérée, son paramétrage est bien celui par défaut, à savoir aucun jours/périodes neutralisés
Vérifier dans les logs kibana que l'appel a bien été tracé et indique l'id du scénario pour le quel les paramètres sont récupérés.
Vérifier avec la base de données que les informations récupérées correspondent bien à celles du scénario édité.

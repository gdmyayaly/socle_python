En tant que TRPPU

Je veux que les informations d'ajout ou de suppression des comptages d'objets soient mise à jour en base de données 

Afin de sauvegarder l'information liée au scénario en cours à chaque "modification"

Pour cela, créer un service dans le POD yb04 qui mettra à jour la table des comptage "trppu_scenario_comptages_manuels" avec l'ajout ou la suppression de trafic pour l'objet concerné.

Lorsque l'utilisateur ajoute un comptage pour un objet, le service ajoute dans la table une ligne avec les informations suivante : 

id_scenario
dt_comptage  (date d'ajout/modification du comptage)
co_produit
nb_produit  (trafic ajouté)
id_rh (crypté)
Lorsque l'utilisateur modifie le trafic d'un comptage, le service mettra à jour la même table pour l'id du scénario en cours et l'objet concerné.

Lorsque l'utilisateur supprimera un comptage, le service supprimera dans la même table la ligne pour l'id du scénario en cours et l'objet concerné.

 

Critères d'acceptances : 

dans l'IHM ajoutez un comptage pour un objet donné et vérifier qu'une ligne a bien été ajouté dans la table "trppu_scenario_comptages_manuels" avec l'id du scénario en cours, l'objet pour lequel le comptage est ajouté et le trafic saisi pour ce comptage
dans l'IHM modifiez un comptage pour un objet donné et vérifier dans la table "trppu_scenario_comptages_manuels" avec l'id du scénario en cours, l'objet pour lequel le comptage est modifié que son nouveau trafic correspond bien à ce qui a été saisi sur l'IHM.
dans l'IHM supprimez le comptage d'un objet et vérifier dans la table "trppu_scenario_comptages_manuels" avec l'id du scénario en cours que la ligne pour l'objet supprimé n'existe plus et a donc bien été supprimé.
Refaire les 3 étapes de façon a ce que 2 ou 3 comptages pour des objets différents soient ajoutés pour le scénario en cours. Modifiez ensuite un comptage puis supprimez en un.
l'id rh est bien crypté dans la table en base.
